# HU-008 — Landing Page Pública

**Como** visitante (no autenticado),
**quiero** ver una página de inicio atractiva que presente el sistema,
**para** entender qué es la aplicación y decidir si registrarme.

## Criterios de Aceptación

**CA-008.1** — La ruta `/` muestra la Landing Page (no redirecciona al login).

**CA-008.2** — La Landing Page contiene: encabezado con logo y nombre del sistema, descripción del propósito, lista de funcionalidades, CTA ("Registrarse" y "Iniciar sesión").

**CA-008.3** — La Landing Page tiene un footer con enlaces a: Términos de Uso, Política de Privacidad, Política de Cookies, y Contacto.

**CA-008.4** — El diseño es responsive (mobile-first) y soporta dark/light mode.

**CA-008.5** — No se requiere autenticación para ver esta página.
